⚙️ Configurações Extras

🔊 Síntese de Voz (TTS)
Saudação ao entrar, leitura do resumo. Use a voz Thalita (PT-BR) ou outra disponível no dispositivo.
📅 Comparativo entre festas
Salva snapshot da festa atual para comparar com eventos futuros. Aparece na aba Relatórios.
📊 Modo Excel EXPERIMENTAL
Edita várias vendas direto na tabela (como uma planilha) — útil para festas grandes com múltiplos dias no mesmo mês. Não altera nenhuma lógica existente: é uma tela extra, isolada.
📱 Instalar como App (PWA)
Habilita instalação como app. Requer servidor http:// — não funciona em arquivo local (file://).
📄 Habilitar aba Relatórios
Mostra a aba dedicada com Fechamento, Ranking, Estoque e Roadmap centralizados.
🎲 Habilitar aba Sorteio
Sorteador de números e nomes para o bingo.
⚡ Manter Venda Rápida aberta após confirmar
Ideal para muitos lançamentos seguidos. Limpa os campos e aguarda próxima venda.
💾 Backup automático (snapshots locais)
Salva até 7 snapshots no IndexedDB. Checksum garante integridade. Mais antigos são removidos automaticamente.

Resetar Sistema Completamente

Remove todos os lançamentos, vendedores e configurações de estoque. Use para começar um novo evento do zero. Rodadas e configurações de preços são mantidas.
ℹ️ Os IDs continuam da numeração atual — isso é correto e garante que backups antigos não colidam com novos dados.
